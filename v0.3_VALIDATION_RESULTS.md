## ⚠️ Known Limitations & Workarounds

1. **Prefab Disk Loading**: Disk loading via `PrefabRegistry::LoadPrefabFromFile` is not fully integrated and will output a warning log. Prefabs should be initialized manually or generated inside the editor code for v0.3.
2. **`.omnixprefab` Format**: Prefabs are serialized in standard `.json` formats instead of the proprietary binary `.omnixprefab` file structure.
3. **Multi-Viewport Window Dragging**: ImGui multi-viewports remain disabled (`ImGuiConfigFlags_ViewportsEnable` cleared) to avoid Vulkan swapchain binding crashes on multi-gpu/multi-monitor setups. Viewport operates within the single dockable main window.
